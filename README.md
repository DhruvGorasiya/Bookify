# Bookify

## 🏠 Overview
Bookify is a full-featured accommodation booking platform inspired by Airbnb. It allows users to list their properties, book accommodations, and manage their travel experiences.

## ✨ Features

### User Features
- User authentication (Sign up, Login, Logout)
- Social authentication (Google, GitHub)
- Profile management
- Booking management
- Favorite listings
- Real-time messaging with hosts

### Property Features
- Property listing creation and management
- Advanced search with filters
- Image upload with multiple photos
- Property categorization
- Location mapping with Google Maps
- Price calculation
- Availability calendar
- Reviews and ratings system

### Booking Features
- Real-time availability checking
- Secure payment processing
- Booking confirmation system
- Trip history
- Cancellation management

## 🚀 Technologies Used

### Frontend
- React.js
- Next.js
- Tailwind CSS
- TypeScript
- Axios
- React Query
- React Hook Form
- Zustand (State Management)

### Backend
- Node.js
- Express.js/Next.js API Routes
- MongoDB
- Prisma (ORM)
- NextAuth.js
- JWT Authentication

### Cloud Services & APIs
- Cloudinary (Image hosting)
- Google Maps API
- Stripe (Payment processing)
- MongoDB Atlas

## 💻 Installation

1. Clone the repository: git clone https://github.com/DhruvGorasiya/Bookify

2. Install dependencies: npm install



## 📱 Usage

1. Register as a new user or log in
2. Browse available properties
3. Filter properties based on:
   - Location
   - Date range
   - Number of guests
   - Price range
   - Property type
4. Book properties
5. List your own property
6. Manage your bookings and listings
7. Communicate with hosts/guests
